# 首次配置与 API Key 获取

## Agent 执行顺序

1. 沿用 Skill 自身的运行环境；缺少时执行 `sh "$SKILL/scripts/setup.sh"`。它在 Skill 内安装 Python 依赖和专用 Chromium，不修改系统 Python。缺少 Python、FFmpeg 或系统权限时说明实际缺项，不假报就绪。
2. `"$RUN" credentials status` 只检查元数据，禁止读取凭据文件值。已配置时直接执行视频任务，不重复引导或要求用户贴 Key。
3. 未配置时执行 `"$RUN" credentials setup`，自动打开本机设置页，保留此进程等待用户完成。需要在 Codex 面板打开时，用输出的本机 URL 调用可用打开工具。
4. 本机页面给出获取步骤和密码输入框。用户粘贴后自动写入当前用户配置，任务自动继续。不要用浏览器工具读取输入框，也不要截图已输入密钥的页面、剪贴板或官网显示密钥的页面。
5. `auto` 会按同一流程处理缺失凭据，再开始已授权的配音生成。保存成功只表示本地配置完成；实际音色权限和额度由首次配音调用验证。失败保留素材，不自动更换音色、开通资源或反复请求。

```sh
"$RUN" credentials setup             # 已有配置则直接沿用
"$RUN" credentials setup --replace   # 仅在用户要求更换 Key 时执行
"$RUN" credentials setup --no-open   # 远程会话不自动打开宿主浏览器
```

默认等待 15 分钟，可用 `--timeout` 指定 1–1800 秒。取消或超时关闭本机服务，未提交不会改动凭据。远程机器的 127.0.0.1 不是用户电脑；需要端口转发或在远程交互终端使用 `credentials set`，不要把配置页暴露到公网。

## 给用户的获取步骤

1. 打开[豆包语音控制台](https://console.volcengine.com/speech/new/overview)，登录火山引擎账号，按官网要求完成账号认证。
2. 选定项目，在「开通管理」开通所选声音对应的语音合成服务。默认小何 2.0 使用语音合成 2.0；开通与费用需要用户在官网确认，不代为购买。
3. 打开同一项目的「API Key 管理」，创建或选择可用的 Key，并复制。
4. 回到 Product Video 本机设置页粘贴，点击「保存并继续」。不需要手动创建 `.env` 或编辑脚本。

这里使用豆包语音 API Key，不是火山方舟 Key、账号通用 Access Key 或旧版 App ID / Access Token。官网导航变更时先核对当前页面，再引导用户，不照着旧坐标乱点。

官方依据：[新版控制台与 API Key 获取](https://www.volcengine.com/docs/6561/1167802?lang=zh)、[语音合成接口](https://docs.volcengine.com/docs/6561/2532486?lang=zh)。前者同时包含声音复刻步骤；普通预置角色无需为了使用本 Skill 购买复刻音色槽位。

## 配置边界

- 登录、验证码、实名认证、服务开通与付款由用户在官网完成；Skill 自动处理本地保存和后续读取。
- 配置文件位于 `~/.config/product-video/credentials.json`，目录权限 0700、文件权限 0600。
- 本机设置页只监听 127.0.0.1，限制 Host / Origin，校验一次性会话令牌，不记录请求内容；提交和取消后结束服务。
- 真密钥不进入对话、命令参数、项目、截图、日志或安装包。测试只能用隔离目录里的合成值；不读取或更换用户现有 Key。
