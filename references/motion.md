# 镜头、转场与操作节奏

准备视频画面或改善已有成片时读取。先沿用产品真实视觉，再选视频的展示方式；不要把视频预设当成产品主题。颜色、时长、镜头都可以覆盖，不改文稿或配音缓存。

## 七种预设

在 `video.style` 指定；不填时为 `product`。七种风格均可使用[文案与图文版式](content.md)，并非只能展示截图。默认产品风格仅有轻微整体推进，截图完整保留；只有明确的 `camera.zoom > 1` 才放大局部。

`video.style: "classic"` 恢复 GitHub 原始 1.1.0 的视觉布局、颜色、字幕与默认淡入曲线，直接在同一引擎内选择。它继续使用修正后的模拟操作时序，也可选用新的转场和正文版式；不会恢复原来点击前就出现结果的缺陷。显式颜色、镜头、转场等字段仍覆盖预设；从其他风格切换时移除不再需要的覆盖项。

| style | 使用场景 | 默认画面与节奏 |
| --- | --- | --- |
| `classic` | 原始版画面与传统产品介绍 | 原版深灰渐变、左侧产品名与居中章节标题、原版截图/字幕位置、0.6 秒淡入淡出、固定镜头与底部进度条 |
| `product` | 产品介绍、功能更新 | 深色舞台、轻微推进、上移章节转场、0.65 秒过渡、适中鼠标速度 |
| `promo` | 短宣传、重点速览 | 深色舞台、缩放章节转场、左推画面切换、0.5 秒过渡、较短停留 |
| `tutorial` | 上手教程、步骤讲解 | 浅色舞台、固定镜头、淡入章节转场、画面直接切换、更慢移动和较长停留 |
| `cinema` | 细节介绍、沉静的产品展示 | 墨黑与冷灰、景深叠化、层叠推进、0.9 秒转场、较长停留 |
| `gallery` | 设计作品、主题与外观展示 | 暖白与棕灰、圆角开幕、固定镜头、0.9 秒转场、较长停留 |
| `minimal` | 工具介绍、简洁功能讲解 | 纸白与灰绿、上移遮罩、固定镜头、0.75 秒转场、普通画面直接切换 |

```json
"video": {
  "style": "product",
  "transition_style": "slide-up",
  "step_transition": "fade",
  "transition": 0.65,
  "camera_motion": "push",
  "cursor_move": 0.65,
  "cursor_hold": 0.18,
  "cursor_linger": 0.8,
  "progress": false,
  "reduced_motion": false
}
```

显式字段覆盖预设。`camera_motion` 只支持 `none` / `push`；`push` 从全图的 98.5% 轻推到 100%，不会靠裁切制造运动。`reduced_motion: true` 关闭推进、局部运镜、滑动和缩放转场，鼠标以离散位置呈现但保留点击与结果的先后顺序。

## 转场选择

引擎支持下列 15 种切换方式，包含直接切换。一个正常产品片通常选两三种形成一致节奏，不需要把效果全部用上。示例脚本中的全效果轮播只用于验收。

| 名称 | 用途 |
| --- | --- |
| `cut` | 直接切换；点击结果、教学步骤、需要保留节奏时 |
| `fade` | 淡入淡出；相同布局状态变化、平静的章节衔接 |
| `slide-left` / `slide-right` | 水平推移；前进、返回、平级页面 |
| `slide-up` | 向上推移；进入下一章节 |
| `wipe-left` / `wipe-right` | 带柔化边缘的擦除；主题或版本揭示 |
| `zoom` | 小幅缩放叠化；宣传章节、强调一个新功能 |
| `blur` | 短暂虚化叠化；跨场景切换，避开阅读正文的时刻 |
| `focus-dissolve` | 景深叠化；上一镜头轻退失焦，新镜头逐渐合焦，适合章节或细节展示 |
| `depth-slide` | 层叠推进；前后画面以不同幅度移动和缩放，适合进入下一层功能 |
| `mask-up` | 上移遮罩；柔边遮罩从下向上揭示画面，配合小幅上移，适合简洁章节衔接 |
| `iris` | 圆角开幕；从中心打开圆角矩形窗口，适合主界面、主题和作品揭示 |
| `split-reveal` | 双侧揭幕；上一镜头分成左右两侧退场，露出下一镜头，适合少量重点展示 |
| `glass-sweep` | 玻璃扫光；窄带柔焦和轻微折射沿切换边缘经过，适合主题或材质对比 |

新增转场建议用 0.7–1.0 秒，先建立全图，再进入细节。`focus-dissolve` 与 `depth-slide` 有轻微缩放，过渡中不安排正文阅读；`glass-sweep` 只影响边界附近，避免整屏亮闪。`split-reveal` 会暂时分开画面，用于章节，避免用于连续点击。六种新效果同样遵守 `reduced_motion`，不会强制启用。

`video.transition_style` 控制章节默认值；`video.step_transition` 控制普通截图切换。章节和步骤均可通过 `transition`（类型名称）与 `transition_duration`（0–2 秒）覆盖。`video.transition` 仍然是时长，兼容旧项目。步骤转场最长占该步骤时长的 30%，避免整个步骤都在过渡。章节转场在配音前的留白完成，不截断旁白。

```json
{"id": "themes", "title": "界面主题", "narration": "已确认的文稿。",
 "transition": "wipe-left", "transition_duration": 0.7,
 "steps": [{"at": 0, "images": ["assets/light.png"]}]}
```

## 有因果顺序的模拟操作

对于 `click` 和 `drag`，当前步骤的 `images` 是**操作后的真实截图**。引擎在该步骤起点先保留上一张图，播放操作，再显示当前图。`at` 是**开始模拟操作**的时间，占本章配音时长的比例；不再代表结果立刻出现。首步先建立操作前状态。

```json
"steps": [
  {"at": 0, "images": ["assets/before.png"], "labels": ["项目列表"]},
  {
    "at": 0.35,
    "images": ["assets/after.png"],
    "labels": ["项目详情"],
    "interaction": {
      "kind": "click",
      "from": [0.5, 0.7],
      "to": [0.12, 0.27],
      "move": 0.65,
      "hold": 0.18,
      "settle": 0.12,
      "linger": 0.8
    },
    "transition": "fade",
    "transition_duration": 0.2
  }
]
```

- `from` / `to`：操作前截图的归一化坐标。`to` 必填；省略 `from` 时沿用上一个指针终点，首次出现时从目标附近进入。移动使用有起停缓冲的曲线，拖动使用直线。
- `move`：移动时长；`hold`：点击前停留，拖动时是起点按下前停留；`settle`：点击或释放后等待多久显示结果；`linger`：结果出现后的指针停留。单位秒。
- `kind: "move"`：指向当前图上的目标，无点击，也不延迟当前截图。`kind: "click"`：移动、停留、按下、等待、显示结果。`kind: "drag"`：必须提供 `from`，起点停留、按下、沿直线拖动、释放、显示结果。
- 不指定时长时使用风格预设；短步骤自动按比例压缩移动、停留和等待，并保留结果可读时间。明确指定的时间装不下时会报错；不要用极短步骤掩盖操作。
- 操作前后都必须为同一视口比例的单图。并排展示、滚动后位置不同或窗口尺寸变化时，先建立新的静态镜头再操作。
- 旧的 `cursor: [x,y]` / `click: true` 仍可用，也会遵守先点击后出现结果的新顺序。不要与 `interaction` 写在同一步。
- 自动采集网页时优先用 `points` 记录真实控件位置，再引用 `capture:before:settings`，见 [采集说明](capture.md)。点击目标应来自**操作前**截图上的控件，不能用结果页面上相似位置猜测。

截图不能还原真实打字、滚动惯性、拖动中的内容布局变化或应用原生动画。`drag` 只模拟指针按住和释放，再显示最终截图。需要这些过程时应采集真实录屏；当前引擎尚不接收录屏素材，不能把两张静态图声称为完整交互记录。

## 局部聚焦

在单图步骤中设置：

```json
"camera": {"zoom": 1.4, "center": [0.6, 0.45]}
```

`zoom` 为 1–2.5，`center` 是原图中的目标中心。镜头从全图平滑推进至目标；移动幅度会限制在图像边缘内。点击期间保持操作前镜头稳定，结果出现后才进入新镜头。鼠标与画面使用相同变换。

放大时先确定要读的完整区域，避免在画面边缘切断正文或按钮。全局概览、对照、教学导航默认不放大。一个细节讲完后用下一步骤的全图恢复上下文；不要让镜头来回追逐每个词。

## 检查与离线样片

`preview` 现在输出移动中、按下、结果、转场中间态和稳定画面，并在 `preview/index.json` 记录秒数。检查点击时屏幕是否仍是操作前状态、目标是否对齐、结果是否有时间读、字幕是否压住标签。预览关键帧通过后，仍需播放成片检查运动。

不调用配音 API 的动效样片（明确标注示例界面和无配音）：

```sh
# 在 scripts/engine 中执行；输出目录必须为空或不存在
.venv/bin/python examples/render_motion_demo.py /path/to/motion-review --style all
# 只验证三种新增风格和六种新增转场
.venv/bin/python examples/render_motion_demo.py /path/to/premium-review --style premium --transitions premium
# 单独验证一种风格或 720p
.venv/bin/python examples/render_motion_demo.py /path/to/tutorial-review --style tutorial --width 1280
```

样片会通过生产合成器生成操作、聚焦、对照及全部转场，再完整解码验证每支 MP4。它不写入正式配音缓存、不读取凭据，也不证明真实应用操作或声音质量已经验证。
