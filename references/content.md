# 文案镜头与图文编排

当介绍需要开场、章节引导、功能要点、正文解释或收尾时读取。`video.style` 决定配色、排版基调和默认节奏；`steps[].content` 决定这个镜头显示什么。原始版 `classic` 与六种增强风格都支持文案、截图及两者混排。

画面主标题、正文、要点和片尾都遵守 [文案与旁白规范](narration.md)：简洁专业、使用陈述句，不用反问、宣传套话或无信息的收尾。片尾镜头按内容需要安排，不为凑结构添加口号。

## 文案的三个位置

- `chapters[].narration` 是完整旁白，继续用于配音与自动字幕。已有确认稿保持不变。
- `steps[].content` 是画面正文：可以是标题、简短解释、功能要点，不必逐字重复旁白。改变它不会重新合成未改动的旁白。
- `captions` 或自动字幕是旁白的时间对齐文本。正文独立放在画面中央安全区，字幕留在底部；不要把全文压到字幕中，也不要把关键词文案冒充完整字幕。

产品演示和更新报告先为每个功能点安排可见证据：成品效果、实际操作、同素材前后对比，或带实际输入和输出的实现示意。旁白解释画面正在展示的变化，正文提炼必要信息。讲技术栈时可将配置或时间轴与渲染结果并排，不连续罗列技术名称。

纯标题适合短暂开场或章节分隔，文字版式示例可以明确展示纯文案能力；不要因为引擎支持 `title` / `bullets` 就把产品演示默认排成连续幻灯片。用户明确要求纯文案片时仍可使用，不为了凑图片虚构产品界面。

检查素材内部的内容：截图、录屏或三维设备里如果仍是文字页，不能据此认为已展示产品。避免把播放样片的网页反复套进画面；优先使用原始界面或直接呈现生成效果。示例界面须明确标注，不能被写成 Skill 自带的产品编辑器。

成片验收按时间轴检查主体占比与停留时长。长段旁白只有标题、重复要点或缩小的静态配图时，应补齐对应的过程或结果镜头，再检查连续播放。保留界面阅读时间，不通过无意义的快速切换填充画面。正文只写有依据的功能、已确认的开发初衷和用户提供的行动入口。

## 三种正文版式

| `content.layout` | 内容 | 图片规则 |
| --- | --- | --- |
| `title` | 主标题，可加上方短标签和正文；用于开场、章节、引言或收尾 | 不填写 `images`，或使用 `[]` |
| `bullets` | 主标题与 1–4 项要点，可加上方短标签 | 不使用图片或 `body`；长列表分步展示 |
| `split` | 主标题与可选正文，旁边放一张完整等比截图 | 必须提供一张图片；`image_side` 选择 `left` / `right`，默认在右侧 |

通用字段：`headline` 必填，最多 120 字符；`eyebrow` 为可选短标签，最多 60 字符。`body` 最多 800 字符，每条 `bullets` 最多 180 字符。这些是输入上限，不保证任何组合都能放进同一镜头。引擎会按实际字体和分辨率测量、换行、在可读范围内缩小字号；仍放不下时在配音前报错，要求拆分镜头，不截断或添加省略号。

```json
"steps": [
  {
    "at": 0,
    "content": {
      "layout": "title",
      "eyebrow": "产品介绍",
      "headline": "产品名称与主要用途",
      "body": "用一两句话说明实际用途。\n也可以明确换行。"
    }
  },
  {
    "at": 0.3,
    "content": {
      "layout": "bullets",
      "headline": "功能概览",
      "bullets": ["第一项已确认能力", "第二项已确认能力", "第三项已确认能力"]
    }
  },
  {
    "at": 0.65,
    "images": ["assets/settings.png"],
    "labels": ["实际设置界面"],
    "content": {
      "layout": "split",
      "headline": "解释这个功能如何使用",
      "body": "简短说明操作目的和已验证的结果。",
      "image_side": "right"
    }
  }
]
```

这些 `at` 值只是结构示例；它们占本章配音时长的比例。按实际旁白调整，给正文阅读和结果展示留时间。长介绍可以拆章，不擅自缩短用户确认稿。`narration` 仍然必填；本次没有新增正式项目的静音或音乐制作流程。

## 运动与操作

正文默认分块淡入并轻微上移；`content.animation: "none"` 可关闭正文入场，`video.reduced_motion: true` 同样关闭。标题、正文与要点分组出现，不做逐字打字。章节与步骤的 `transition` / `transition_duration` 可继续使用十五种已有切换方式。

`split` 支持现有 `interaction`、`cursor`、`camera`。点击或拖动前后必须使用相同版式与 `image_side`，图片比例也必须一致；先显示操作前画面及说明，再模拟操作，之后显示结果图及对应正文。鼠标坐标始终相对源截图，不按整张视频或文字列计算。完整截图和 `split` 之间切换时，先建立新静态镜头再开始操作。

纯文案画面不接受鼠标坐标或局部运镜。截图标签仍用 `labels`，不要把大段正文塞进标签。纯图镜头继续使用既有 `images` 配置，无需添加 `content`。

## 离线验收样片

在 `scripts/engine` 中运行，输出目录必须为空或不存在：

```sh
.venv/bin/python examples/render_story_demo.py /path/to/story-review --style gallery
```

脚本生成原始风格样片及包含三种正文版式、完整截图、模拟点击和字幕的混排样片，输出 MP4、SRT、项目、关键帧与校验结果。可以将 `--style` 换成七种风格中的任意一种。样片使用静音与明确标注的示例界面，不调用配音 API；正式视频继续通过 `auto` / `build` 生成配音与成片。
