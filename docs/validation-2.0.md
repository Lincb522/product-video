## 验证边界

- 654 张画面证明全库可执行，并用于抽样视觉复核；它们不是 218 段完整视频的逐帧验收。
- 示例素材、固定截图切片和自定义字形需按目标产品调整。未验证每个组件对任意内容、任意画幅都能直接适配。
- 语音联调使用已生成的三段缓存。没有为本次测试重新调用所有音色，也未对新的付费语音请求或所有语言作验证。
- 成片的声音轨与字幕时序已核对，未进行独立的听感审听。正式发布前仍需复核目标产品的文案、素材与听感。
- 本记录覆盖上述 macOS 环境；不将其视为 Windows、Linux 或其他浏览器的完整验证。

## 复现入口

```sh
cd scripts/engine
PYTHONPATH=. .venv/bin/python -m unittest discover -s tests -v

cd ../../vendor/video-shotcraft/workbench
npm run test:integration
npm run build
```

全库抽帧通过 `workbench/scripts/product-video.mjs smoke REQUEST.json` 执行。请求指定 `publicDir`、输出目录、目录中全部 `demo-<Component>` 标识及可选的 `resume`；生成逐组件的 `coverage.json` 和起始、中间、结束帧 PNG。

项目验证使用引擎的 `check`、`prepare-motion`、`studio` 与 `render`。工作台旁白成功后检查分轨与时长，再通过“导出成片”取得当前剪辑和校验文件。
