# 二维风格更新与验证 · 2.0.1

六种增强风格此前共用截图区域、标题位置和边框，主要区别是配色、转场与指针速度。2.0.1 在 `presentation.py` 中分别实现构图、表面处理和入场运动；`text_scenes.py` 负责对应的正文层级与对齐。

| 风格 | 画面区别 | 入场 |
| --- | --- | --- |
| product | 侧栏章节标题、右侧主界面、柔和投影 | 上移归位与轻微缩放 |
| promo | 大标题、强调色错位底板 | 从右侧进入并缩放归位 |
| tutorial | 当前步骤导览、固定界面 | 保持稳定，按操作结果更新步骤标记 |
| cinema | 宽幅暗色舞台、底部章节标题 | 完整界面缓慢推进 |
| gallery | 装裱边框、居中标题、双图错落陈列 | 轻抬升与缩放 |
| minimal | 平面网格、细分隔线、无投影 | 固定位置由下向上揭示 |

`classic` 保持原始布局；七个时间点的渲染结果与改动前逐字节一致。新的入场不介入指针操作、显式局部镜头或图文并排的坐标控制。减少动态效果设置会直接显示完整画面。

- Python 完整回归：109 项通过，包括原有采集、操作、字幕、配音缓存、录屏、三维与 Shotcraft 整合测试。
- 六项新增专项检查：同色配置下构图仍有区别；720p/1080p 截图四角完整；入场与减少动态效果；点击前后状态；长标题与步骤导览；侧栏标题不留单字尾行。
- 同一组截图和时序输出七支 12.8 秒视频，逐支通过尺寸、时长、音轨和完整解码检查。另生成约 89.6 秒的逐款对比片和 12.8 秒的六款同屏对比片。
- 逐款输出并查看截图、文字页与图文页样张。对比页在 1280 和 390 像素宽度检查，七支视频均完成浏览器播放验证。
- 使用已有旁白缓存生成新的二维片段，经过 Remotion 主时间轴渲染六张预览，复核标题、真实截图与字幕位置。
- 新的二维实现文件加入原生片段缓存签名，修改构图后重新渲染对应片段。
- 打包时保留凭据管理的 Python 源模块，继续排除实际凭据文件。完整 ZIP 在空目录解压后通过 Python CLI、凭据模块和二维模块导入检查。

## 使用边界

这些风格作用于原生二维镜头。`steps[].shotcraft` 的构图由指定组件决定，单独修改 `video.style` 不会换掉该组件。普通截图默认完整等比展示；局部裁切仍须明确配置 `camera`。

对比片是无旁白的示例素材验证视频，没有为本次检查调用语音合成 API。混合预览沿用此前配音，不代表制作了新的正式介绍稿。

复现入口：

```sh
cd scripts/engine
PYTHONPATH=. .venv/bin/python -m unittest discover -s tests -v
.venv/bin/python examples/render_style_comparison.py /path/to/empty-review-directory
```

可同时传入 `--before` 和 `--after` 指定同一视口的两张截图；输出目录必须为空。说明与参数见 [二维风格和动效](../references/motion.md)。
