先配置配音服务

完成这一次，之后制作视频会自动使用已保存的密钥。

怎么获取 API Key

  1. 打开豆包语音控制台，登录火山引擎账号，按控制台提示完成账号认证。
  2. 选定项目，在「开通管理」开通所选声音需要的语音合成服务。默认小何 2.0 对应语音合成 2.0；开通和费用由你在官网确认。
  3. 在同一项目的「API Key 管理」创建或选择可用的 Key，复制后粘贴到本页的密钥输入框。

这里使用豆包语音的 API Key，不是火山方舟 Key，也不是旧版 App ID / Access Token。

官方控制台与 Key 指引语音接口文档

保存到这台电脑

无需编辑配置文件，也不用把 Key 发给 Agent。

密钥仅保存到当前用户的本地配置目录，不进入视频项目和分发包。该页面不调用配音接口；生成旁白时按语音服务用量计费。
